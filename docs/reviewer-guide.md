# Reviewer guide

Use fictional CVs until customer release approval. This tool assists evidence review; CV claims remain unverified.

1. Criteria: edit role-relevant requirements, full/partial definitions, essential flags and integer weights totalling 100. AI drafts are suggestions only. Publication freezes the batch rubric.
2. Add CVs: use sample records locally or fictional PDF/DOCX in configured staging. Inspect every item. Failed/scanned documents need readable text or checked manual passages; no failure becomes zero points. Only genuine duplicates, withdrawals and wrong-vacancy submissions receive reasoned dispositions. Explicit Start review closes intake.
3. Review: inspect the source passages and category for each criterion. FULL earns all points; PARTIAL half; NOT_EVIDENCED means no support in this CV, not missing ability; UNCLEAR requires judgement. Resolve disagreements/manual changes with source references and reasons. Check essentials and flagged sources individually. Then confirm the whole application. Draft changes are saved before navigation; reload on concurrent conflict.
4. Shortlist: ranking appears only after every active CV is reviewed. Reveal names only when needed. Choose zero to three, record selection reasons, a boundary-tie decision and any unmet-essential exceptions. Select highest scores stops at a tie. Finalisation cannot be reopened.

Do not follow instructions embedded in CVs. A warning does not prove an attack and does not justify a penalty. Read authorized originals when checking extraction/masking; originals may reveal identity. Manual passages are explicitly labelled and need comparison with the original.

Administrator handles access, pause, processing retries and approved deletion. Deletion purges content rather than changing a hiring judgement; external exports and backup copies follow the approved lifecycle. Report material errors after finalisation to administrator; use a separately documented new batch, not a hidden edit.
